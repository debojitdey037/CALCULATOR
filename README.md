# Calculator

A simple, clean calculator web app built with vanilla HTML, CSS, and JavaScript — no frameworks, no build step, just open it in a browser.

## Features

- Basic arithmetic: addition, subtraction, multiplication, division, and percentage (`%`)
- Decimal point support for floating-point calculations
- Live expression display so you can see what you're typing
- **CE** (Clear Entry) — clears the last entered value
- **CA** (Clear All) — resets the calculator completely
- Fully client-side — works offline once loaded, no server required

## Tech Stack

- **HTML5** — structure and layout (`index.html`)
- **CSS3** — styling (`style.css`)
- **JavaScript (vanilla)** — calculator logic and button handling (`app.js`)

## Project Structure

```
CALCULATOR/
├── index.html   # Markup for the calculator UI
├── style.css    # Styling for the calculator
└── app.js       # Core calculator logic
```

## Getting Started

No installation or dependencies needed.

1. Clone the repository
   ```bash
   git clone https://github.com/debojitdey037/CALCULATOR.git
   ```
2. Open `index.html` in any web browser (double-click it, or use an extension like VS Code's Live Server for auto-reload during development)

## Usage

- Click the number and operator buttons to build an expression
- Press **=** to evaluate the expression and see the result
- Press **CE** to clear the current entry
- Press **CA** to clear everything and start fresh
